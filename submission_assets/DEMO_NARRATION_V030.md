# Fibi v0.30 Narration Script

This is Fibi.

She is not a corporate assistant with a mascot glued on top. She is a tiny desktop lifeform: sleepy, playful, local-first, and designed around presence before intelligence.

Most AI tools tie identity to a model session. Change the model, clear the chat, or lose the account state, and the character disappears. Fibi is built differently. The model can help her speak, but it does not own who she is.

Her mood, memory, permissions, workflow rules, and safety boundaries live in local systems on the user's machine. The router decides what should stay local, what needs a model, and what should be refused. A greeting can be answered instantly. A date or status command does not need a language model. A complex question may use a replaceable local provider, but Fibi's identity stays outside it.

Here is her notebook. These are fictional demo memories in an isolated profile. I can search them, pin one, approve one, archive one, or delete one. That matters because memory should not be a mysterious black box. The user owns the notebook.

Fibi also has consent controls. Memory learning can be paused and resumed. Sensitive memories require care, and secret-shaped text is blocked instead of quietly stored. In this demo, the key-like value is fake, but the guard still treats it as something Fibi should not keep.

Workflow recipes show the same philosophy. They are guided rituals, not autopilot. Fibi can help debug a project, prepare a release, or run a startup check, but risky steps keep confirmation boundaries. She explains what she can do, what is disabled, and what she refuses.

Codex helped build the local architecture, tests, documentation, release checks, memory review center, and submission assets during the build period. The language-model provider supplies replaceable reasoning or text generation when allowed. It does not own Fibi's memory, consent, or character.

This is still a beta. It is not production security, not AGI, and not autonomous agency. But it is a working direction for AI companions that users can inspect, reset, and trust locally.

The model can change. Her identity and history remain. The user owns the notebook. This is Fibi.
